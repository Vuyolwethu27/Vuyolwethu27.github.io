# Work Readiness E-Portfolio

This repository contains a Markdown-based GitHub Pages portfolio for the CPUT work-readiness assessment.

## Publish
1. Create a **public** GitHub repository named `YOUR-USERNAME.github.io` (replace with your actual GitHub username).
2. Upload the contents of this folder to the **root** of that repository, including `_config.yml`.
3. In **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, `main`, `/(root)`, then Save.
4. Once deployed, open `https://YOUR-USERNAME.github.io/` and test all links.
5. Add actual evidence screenshots as `assets/github-account.png` and `assets/github-pages.png`.
6. Replace the mock interview placeholder URL with the real shareable video link.
7. Replace placeholders in the CV and reflections, and verify all statements are true.
8. Submit the live GitHub Pages URL on Blackboard.

The `index.md`, `cv.md`, `evidence.md`, and `reflections.md` pages use Jekyll front matter for GitHub Pages.
