
# User Stories and Tasks – QR Code Attendance System

## Introduction
This document presents user stories and development tasks for the QR Code Attendance System.

## User Story 1: Student Login
**As a** student, **I want to** log in securely, **so that** I can access my attendance information.

### Tasks
- Design the student login interface.
- Implement student authentication.
- Validate login credentials.
- Test successful and unsuccessful login attempts.

## User Story 2: QR Code Generation
**As a** lecturer, **I want to** generate a QR code for a class session, **so that** students can register their attendance.

### Tasks
- Design the QR code generation interface.
- Generate a unique QR code for a class session.
- Associate the QR code with the correct class.
- Test QR code generation.

## User Story 3: QR Code Scanning
**As a** student, **I want to** scan a QR code, **so that** my attendance can be recorded.

### Tasks
- Design the QR code scanning interface.
- Implement QR code scanning.
- Validate the scanned code.
- Save attendance records.
- Test scanning functionality.

## User Story 4: View Attendance Records
**As a** lecturer, **I want to** view attendance records, **so that** I can monitor student participation.

### Tasks
- Design the attendance dashboard.
- Retrieve attendance records from the database.
- Display attendance by class and date.
- Test attendance record retrieval.

## User Story 5: Attendance Reports
**As an** administrator, **I want to** generate attendance reports, **so that** I can monitor attendance trends.

### Tasks
- Design the reporting interface.
- Retrieve attendance data.
- Generate attendance summaries.
- Test report accuracy.

 ## User Story: Prevent Duplicate Attendance Check-ins
**As a** adiministrator 
**I want to** prevent duplicate check-ins for the same student in a single session  
**So that** attendance metrics remain accurate and cannot be manipulated.

##  Tasks
- Establish Punctuality & Status Thresholds
- Capture Device & Session Metadata
- Prevent Duplicate Scans & Re-Entries
- Track & Display Real-Time Headcounts
   
## My Contribution
My role in the QR Code Attendance System project involved clarifying requirements and helping translate business needs into user stories and also help designing and developing the actual system.
