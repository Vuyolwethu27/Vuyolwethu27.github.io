## My Individual Contributions

My responsibilities included clarifying system
requirements and helping translate business
needs into user stories, designing and developing the system.

### Activities I Contributed To

- Reviewed the QR attendance user stories and identified tasks for session initiation, QR scanning and duplicate-scan prevention
- I also contributed to the documentation, designing and development of the system
- As a System User (Student, Lecturer, Admin) I want to log in securely with my institutional credentials So that I can access features specific to my assigned role.
- I participated in a discussion where we need to identify the stakeholders of the project, what the technical architecture and specifications the system will use.

## Challenges Encountered

### Challenge 1
How to generate the QR code.

### How It Was Addressed
We were able to make the system be able to generate the QR code by researching and practicing how to generate the QR codes using the different tools available. I contributed by doing the research on the different tools and ways to create the QR code. 

## Lessons Learned
This project helped me learn more about having to communicate regularly with my team members in order for us to always be on the same page, to ask for help when I struggle with something. I also learnt that I need to be flexible with my work when working on an agile project.
